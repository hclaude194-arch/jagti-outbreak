# Jagti Outbreak: notes for Claude

Unity 6 (6000.0 LTS) URP project. The owner tests it in Unity on a laptop with Intel Iris Xe graphics, 16 GB RAM. Unity is not available in the cloud container, so nothing can be run there (a type check is possible, see below). Keep C# conservative, and say plainly in PRs that code is untested until the owner presses Play.

- Layout source of truth: `tools/layout/generate_layout.py` → `Assets/Data/campus_layout.json`. Map units are about 1 m. The origin is the central roundabout (map 414, 996), and map up is +Z. After editing, bump `VERSION` (Unity rebuilds the scene when it rises), then run `generate_layout.py` and `generate_terrain.py` in that order.
- Terrain: `tools/layout/generate_terrain.py` (numpy) writes the heightmap, splat, grass and tree data; `--preview` draws a top-down check image into `tools/layout/preview/` (gitignored). Its hilltop shape is a design, not survey data.
- C# type check without Unity: `apt-get install mono-mcs`, take UnityEngine.dll/UnityEditor.dll from the NuGet package `unity3d.sdk` 2021.1.14.1, stub URP and Unity.AI.Navigation types, and compile with `mcs`. This catches typos but not Unity 6-only API differences.
- The scene is generated by `Assets/Editor/CampusGreyboxBuilder.cs` (menu Jagti > Build Campus); do not hand-edit `Campus_Greybox.unity`. Textures and tree models are made from code into `Assets/Generated` (gitignored).
- Input: classic Input Manager (`UnityEngine.Input`), not the Input System package.
- Performance targets: 30 fps on Iris Xe, 0.8 render scale, baked lighting, fog-limited draw distance, zone streaming later.
- Blender works headless in the container through `pip install bpy` (Python 3.13). Use it to generate FBX buildings, stored via Git LFS.
- Building names come from the official campus plan. Treat names marked "?" on the vision map as guesses.
