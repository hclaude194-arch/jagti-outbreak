# Jagti Outbreak: notes for Claude

Unity 6 (6000.0 LTS) URP project. The owner tests it in Unity on a laptop with Intel Iris Xe graphics, 16 GB RAM. Unity is not available in the cloud container, so nothing can be run or compiled there. Keep C# conservative, and say plainly in PRs that code is untested until the owner presses Play.

- Layout source of truth: `tools/layout/generate_layout.py` → `Assets/Data/campus_layout.json`. Map units are about 1 m. The origin is the central roundabout (map 414, 996), and map up is +Z. Regenerate the JSON after editing.
- The scene is generated by `Assets/Editor/CampusGreyboxBuilder.cs`; do not hand-edit `Campus_Greybox.unity`.
- Input: classic Input Manager (`UnityEngine.Input`), not the Input System package.
- Performance targets: 30 fps on Iris Xe, 0.8 render scale, baked lighting, fog-limited draw distance, zone streaming later.
- Blender works headless in the container through `pip install bpy` (Python 3.13). Use it to generate FBX buildings, stored via Git LFS.
- Building names come from the official campus plan. Treat names marked "?" on the vision map as guesses.
